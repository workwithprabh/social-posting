# Script reviews

One log per client: `capital-hyundai.md`, `dee-emm-hyundai.md`, `mr-hyundai.md`, `mahindra-arav.md`,
`dee-emm-mahindra.md`, `car-and-bike.md`. Each script reviewed in chat gets one entry, newest at the bottom:

```
## 2026-11-14 · <topic>
- Score: <overall>/10 (hook x, idea x, accuracy x, flow x, voice x, CTA x, shootability x)
- Main fixes: <2-4 short bullets>
- To verify: <facts not confirmed from the brand's own site, or "none">
```

`PATTERNS.md` tracks problems that show up in more than one client's scripts.

Scoring criteria (each out of 10): hook (first 2 s), one clear idea, accuracy, flow and length (30-60 s),
client voice and language (`captions/STYLE.md`), call to action, ease of shooting. Facts are checked against
the brand's own site or press release; prices and offers carry "ex-showroom, T&C apply".
