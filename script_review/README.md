# Script reviews

One log per client: `capital-hyundai.md`, `dee-emm-hyundai.md`, `mr-hyundai.md`, `mahindra-arav.md`,
`dee-emm-mahindra.md`, `car-and-bike.md`. Each script reviewed in chat gets one entry, newest at the bottom:

```
## 2026-11-14 · <topic>
- Score: <overall>/10 (hook x, idea x, accuracy x, flow x, voice x, CTA x, shootability x)
- Main fixes: <2-4 short bullets>
- To verify: <facts not confirmed from the brand's own site, or "none">
```

`PATTERNS.md` tracks problems that show up in more than one client's scripts.

Scoring criteria (each out of 10): hook (first 2 s), one clear idea, accuracy, flow and length (30-60 s),
client voice and language (`captions/STYLE.md`), call to action, ease of shooting. Facts are checked against
the brand's own site or press release; prices and offers carry "ex-showroom, T&C apply".

Phone numbers never go in the script (user, 14 Nov 2026): the spoken CTA names the dealership only. Numbers stay
in the caption's contact block.

## How it should sound (user feedback, 14 Nov 2026)
Write the way a salesperson talks on the floor, not like a brochure. Prefer everyday words: "mileage" over
"efficiency" (keep "certified" for brand figures), "kharcha" over "running-cost comparison", "kaunsa better
padega", "ek baar aaiye", "test drive toh banta hai". Read each line aloud; if nobody would say it to a customer
(e.g. "daily running leke aao"), rewrite it. Brand facts can be said plainly ("dono mein same 200 Nm") without
"Mahindra ke hisaab se", as long as the number is the brand's own.

## Script format to share (user, 14 Nov 2026, always)
The rewritten script goes to the presenter as plain paragraphs: no timings, no tables, no labels. One paragraph
per beat (hook, fact, doubt/answer, extra point, CTA), blank line between them; a question and its answer sit on
consecutive lines in the same paragraph. Scores, fact check, shot list and thumbnail come separately, after it.
Reference: the final Mahindra Arav XUV 3XO ZNG script in `mahindra-arav.md`.
